## What AI Runner is

Although the website lives under the broader Flushnet API path, the public branding leads with **AI Runner**.

For GitHub, the repository should be framed around **AI Runner** as the app, while referring to **Flushnet API** as the underlying platform and transport layer.

AI Runner is presented as a practical execution layer for:

- browser automation
- terminal execution
- file operations
- AI agent actions
- sandbox and VM workflows
- multi-node and parallel execution
- dashboard + API + AI assistant control

## Installers

The installer page should be highlighted strongly in this repository because it is the main download and onboarding entry point for users who want to connect a real machine.

Installer page:  
https://www.flushnet.net/api/installer.php

Typical runtime commands shown in the public workflow:

### macOS
```bash
./FlushnetRuntimeLauncher install
./FlushnetRuntimeLauncher start
./FlushnetRuntimeLauncher status
./FlushnetRuntimeLauncher stop
```

### Windows
```powershell
FlushnetRuntimeLauncher.exe install
FlushnetRuntimeLauncher.exe start
FlushnetRuntimeLauncher.exe status
FlushnetRuntimeLauncher.exe stop
```

More details: [docs/installers.md](docs/installers.md)

## Main capabilities

### Browser automation
Open websites, click, type, capture screenshots, and run repeatable browser automation on connected machines.

### Terminal execution
Run shell commands, inspect output, install packages, and operate on real machines or sandbox environments.

### File operations
Read, write, list, move, and synchronize files across connected environments.

### AI agent tasks
Turn natural-language requests into real actions across browser, terminal, files, apps, and connected services.
