# Installers

[Back to README](../README.md)

The installer page is one of the most important public pages for onboarding because it is where users can download and connect a real machine.

## Official installer page

https://www.flushnet.net/api/installer.php

## Why highlight it in GitHub

This page is the clearest download-oriented entry point for users who want to:

- install the local runtime
- connect a Windows or Mac machine
- move from sandbox usage to native execution
- start testing real browser, terminal, and file tasks

## Runtime commands

### macOS
```bash
./FlushnetRuntimeLauncher install
./FlushnetRuntimeLauncher start
./FlushnetRuntimeLauncher status
./FlushnetRuntimeLauncher stop
```

### Windows
```powershell
FlushnetRuntimeLauncher.exe install
FlushnetRuntimeLauncher.exe start
FlushnetRuntimeLauncher.exe status
FlushnetRuntimeLauncher.exe stop
```
