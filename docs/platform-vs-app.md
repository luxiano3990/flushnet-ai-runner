# Platform vs app

[Back to README](../README.md)

For GitHub, the distinction should be explicit.

## AI Runner

AI Runner is the app / product / user-facing operator layer.

Public product URL:

https://www.flushnet.net/api/airunner

## Flushnet API

Flushnet API is the broader platform path underneath AI Runner.

Main platform URL:

https://www.flushnet.net/api/

## Recommended wording

Use wording like this in GitHub:

> AI Runner is the application layer for executing browser, terminal, file, and AI tasks across machines and sandboxes. It runs on top of the Flushnet platform and API.

## Practical rule

When writing repository copy:

- lead with **AI Runner**
- mention **Flushnet API** as the platform layer
- keep installers, docs, help, and support links easy to find
