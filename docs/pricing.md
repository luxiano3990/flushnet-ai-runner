## Plans highlighted publicly

### Free
- sandbox access
- 100 commands per day
- basic GPT access

### Pro
- native machine control
- 5,000 commands per month
- file tools
- terminal access
- non-expiring GPT / chat access code

### Power
- everything in Pro
- 20,000 commands per month
- job queue
- multi-node execution
- priority queue
- non-expiring GPT / chat access code
