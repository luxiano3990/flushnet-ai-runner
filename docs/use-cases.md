# Use cases

[Back to README](../README.md)

The public AI Runner page describes practical execution across browser, terminal, AI, and connected-device flows.

## Browser tasks

- open a site
- click and type
- capture screenshots
- run repeatable browser automation

## Terminal and file tasks

- run shell commands
- inspect output
- move files
- validate changes
- work in a sandbox first when needed

## AI and batch jobs

- launch compute workflows
- run repository jobs
- repeat tasks across one or more nodes

## Example end-user requests shown publicly

- organize my computer files
- automate and run this workflow
- fill in this online form for me
- build and test a mobile app
- run a program on my computer
- write and post my new event to my Facebook page
- search documents and write a report
- schedule an appointment
- read Telegram and WhatsApp messages
- use live voice or mobile camera with AI Runner
